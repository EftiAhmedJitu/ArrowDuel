# ArrowDuel
🏹 120 FPS 2D Archery Game built in pure Java (Android). Includes 5 Modes (Story, Survival, Titan Boss, LAN Duel, Practice), 7 Elemental Bow models (Freeze, Fire, Void, Venom), ballistic physics, smart AI, Bangladesh maps (Boral River, Sajek), and offline Hotspot multiplayer via Sockets.
