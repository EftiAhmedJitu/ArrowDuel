# 🏹 Arrow Duel (অ্যারো ডুয়েল)
### A 2D Stickman Archery Action Game Built with Pure Java & Android SDK

**Arrow Duel** is an action-packed 2D stickman archery duel game developed entirely using **Java and Android SDK**. The project is designed to run directly in Android Studio and features dynamic gameplay, intelligent enemy AI, elemental bows, realistic ballistic physics, multiple game modes, and an immersive gaming experience.

**Arrow Duel** একটি অ্যাকশন-প্যাকড 2D স্টিকম্যান আর্চারি ডুয়েল গেম, যা সম্পূর্ণ **Java এবং Android SDK** ব্যবহার করে তৈরি করা হয়েছে। গেমটিতে রয়েছে ডাইনামিক গেমপ্লে, স্মার্ট Enemy AI, Elemental Bow, বাস্তবসম্মত Ballistic Physics, একাধিক গেম মোড এবং আকর্ষণীয় গেমিং অভিজ্ঞতা।

**English:**

## 3. ⚡ Elemental Neon Bows | এলিমেন্টাল নিয়ন বো

**English:**

The game features multiple special bows with unique visual effects and abilities:

- **Lightning Bow:** Blue electric sparks and a chance to stun enemies.
- **Fire Bow:** Explosive fire trails and splash damage.
- **Golden Bow:** Radiant golden trail with bonus coin drops.
- **Void Bow:** Dark purple gravity-pull effect.
- **Venom Bow:** Green poison damage effect.

Additional mechanics:

- Realistic arrow trajectory.
- Dotted trajectory prediction line.
- Physics-based arrow movement.

**বাংলা:**

গেমটিতে বিভিন্ন বিশেষ ক্ষমতাসম্পন্ন এলিমেন্টাল বো রয়েছে:

- **Lightning Bow:** নীল ইলেকট্রিক স্পার্ক এবং শত্রুকে Stun করার সম্ভাবনা।
- **Fire Bow:** বিস্ফোরক আগুনের ট্রেইল এবং Splash Damage।
- **Golden Bow:** সোনালি আলোর ট্রেইল এবং অতিরিক্ত কয়েন পাওয়ার সুবিধা।
- **Void Bow:** গাঢ় বেগুনি Gravity Pull ইফেক্ট।
- **Venom Bow:** সবুজ বিষাক্ত ড্যামেজ ইফেক্ট।

অতিরিক্ত মেকানিক্স:
- Drag করে ধনুক তাক করা এবং স্ট্রিং টেনশন।
- বাস্তবসম্মত তীরের গতিপথ।
- ডটেড ট্র্যাজেক্টরি প্রেডিকশন লাইন।
- Physics-based Arrow Movement।

# 🚀 Installation & Setup | ইনস্টলেশন ও সেটআপ

### English Version

Follow these steps to run Arrow Duel in Android Studio:

1. Install and open Android Studio.
2. Select **Open an Existing Project**.
3. Navigate to the cloned or downloaded ArrowDuel project folder.
4. Select the project root directory and click **OK**.
5. Allow Android Studio to complete Gradle Sync.
6. Connect an Android device using USB debugging or start an emulator.
7. Click the green **Run (▶)** button to build and launch the game.

**Build Configuration:**
- Gradle Version: 8.9
- Android Gradle Plugin (AGP): 8.6.1

### বাংলা Version

Android Studio-তে Arrow Duel চালানোর জন্য নিচের ধাপগুলো অনুসরণ করুন:

১. Android Studio ইনস্টল করে ওপেন করুন।

২. **Open an Existing Project** অপশন নির্বাচন করুন।

৩. Clone অথবা Download করা ArrowDuel Project Folder খুঁজে বের করুন।

৪. Project-এর Root Directory নির্বাচন করে **OK** দিন।

৫. Android Studio-কে Gradle Sync সম্পন্ন করতে দিন।

৬. USB Debugging চালু করে Android ফোন কানেক্ট করুন অথবা Emulator চালু করুন।

৭. সবুজ **Run (▶)** বাটনে ক্লিক করে গেমটি Build ও Run করুন।

**Build Configuration:**
- Gradle Version: 8.9
- Android Gradle Plugin (AGP): 8.6.1

# 📦 APK Build & Location | APK তৈরি ও অবস্থান

**English:**

To generate a debug APK:

1. Open the project in Android Studio.
2. Navigate to **Build → Build Bundle(s) / APK(s) → Build APK(s)**.
3. Wait for the build process to finish.
4. Locate the generated APK at:

`app/build/outputs/apk/debug/app-debug.apk`

You can transfer this APK to an Android device and install it.

**বাংলা:**

Debug APK তৈরি করতে:

১. Android Studio-তে Project ওপেন করুন।

২. **Build → Build Bundle(s) / APK(s) → Build APK(s)** নির্বাচন করুন।

৩. Build সম্পন্ন হওয়া পর্যন্ত অপেক্ষা করুন।

৪. তৈরি হওয়া APK ফাইলটি পাবেন:

`app/build/outputs/apk/debug/app-debug.apk`

এই APK ফাইলটি Android ফোনে নিয়ে Install করে গেমটি খেলতে পারবেন।
